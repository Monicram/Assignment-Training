Task 2.2 

1.What fields appear in the PUT response body vs the PATCH response body?
PUT: id, title, body, userId (all fields are replaced).
PATCH: Only the title is updated, while the other fields remain unchanged.
2.Why did PATCH only need one field in the body?
Because PATCH updates only the specified field instead of replacing the entire resource.
3.When would you choose PUT over PATCH in a real intern dashboard API?
I would use PUT when I want to replace all the intern details. I would use PATCH when I only want to update one field, such as the score or attendance.

204 No Content is more appropriate because the resource is deleted successfully and no response body is needed.

Task 4.2 

1.Did the fake token cause a 401? Why not?
No. JSONPlaceholder does not validate the Authorization header, so it returned 200 OK.
2.In a real API, what would the server do with the Authorization header?
The server checks whether the token is valid and whether the user is authenticated.
3.What is the difference between 401 and 403?
401 Unauthorized: User is not authenticated or the token is invalid.
403 Forbidden: User is authenticated but does not have permission to access the resource.
